# Verjaardagen → iOS Agenda

Jaarlijks herhalende verjaardagen van mijn Facebook-vrienden (alleen dag en maand).
De lijst staat in `docs/_data/verjaardagen.csv`; GitHub Pages (Jekyll) maakt daar `verjaardagen.ics` van.

## Toevoegen
Open op iPhone: https://rashruf.github.io/verjaardagen-calendar/ → Abonneer → Account: iCloud.

## Instellingen
- **Pages**: Deploy from a branch → `main` / `/docs`.

## Bijwerken
Pas `docs/_data/verjaardagen.csv` aan (naam,maand,dag). De agenda op je apparaten volgt vanzelf.
